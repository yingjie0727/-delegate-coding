本包脚本的离线测试共 76 项：75 项通过，1 项 DPAPI 测试因受限 Windows 用户未加载相应用户配置而跳过。离线测试使用假模型和假密钥，不等同于厂商真实兼容性验证。真实 API 小任务由用户自己的 Windows 终端发起；GPT 独立检查没有读取密钥。

此次分享包还检查了源码语法、本地文档链接、文件白名单、个人路径/密钥样式、文件哈希和压缩包完整性。官方 quick_validate.py 因开发机可用 Python 缺少 PyYAML 未运行，没有把它标记为通过。

本轮主要 Windows 修复：独立配置必须声明本机沙箱后端；后端纳入任务配置指纹；独立 codex-home 放在私有 profile 下；增加不调用 API 的环境检查。没有关闭沙箱，也没有更改主 Codex 登录或模型菜单。

当前 API 实测仍需要用户启动一次本机入口。安装 Skill 并不会自动增加 MCP 服务、原生模型菜单或桌面软件控制权限。执行器报告完成后，GPT 仍要检查实际差异、受保护文件和测试。
