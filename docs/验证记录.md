## 使用边界

桌面路线需要用户复制 HANDOFF.txt，不会自动操作 WorkBuddy 或 ZCode。没有创建定时任务、监听服务或消息发送器。API 路线只支持执行器实际兼容的 Responses 服务；不同 API profile 分开保存凭证，任务创建时绑定公开配置。

同一 checkout 必须始终复用同一个 board。锁只能协调使用该 board 的任务，不能阻挡其他软件或人工修改。allowed_paths 是任务约束与事后检查，不是细粒度操作系统沙箱。助手的完成报告必须经过 GPT 对实际代码和测试的检查。

本仓库提供源码版本，安装方法见 README.md。
