本包脚本的离线测试共 89 项：其中 76 项为原有协议与 API 执行器测试，另 13 项覆盖 CLI 自动派发与两份 bundle 的一致性；DPAPI 测试在受限 Windows 用户下按条件跳过。离线测试使用假模型和假密钥，不等同于厂商真实兼容性验证。真实 API 小任务由用户自己的 Windows 终端发起；GPT 独立检查没有读取密钥。

此次分享包还检查了源码语法、本地文档链接、文件白名单、个人路径/密钥样式、文件哈希和压缩包完整性。官方 quick_validate.py 因开发机可用 Python 缺少 PyYAML 未运行，没有把它标记为通过。

本轮主要 Windows 修复：独立配置必须声明本机沙箱后端；后端纳入任务配置指纹；独立 codex-home 放在私有 profile 下；增加不调用 API 的环境检查。没有关闭沙箱，也没有更改主 Codex 登录或模型菜单。

当前 API 实测仍需要用户启动一次本机入口。安装 Skill 并不会自动增加 MCP 服务、原生模型菜单或桌面软件控制权限。执行器报告完成后，GPT 仍要检查实际差异、受保护文件和测试。

## 2026-11-15 更新

新增 `cli` 路线：任务创建时绑定 CodeBuddy CLI 的绝对路径与可选模型，`run-cli` 自动拉起进程、等待报告、超时终止进程树，未提交报告时由协议代记失败。新增 DSH 版技能目录，与 GPT 版共用同一套脚本和协议文档，并由 `test_bundle_parity.py` 保证两份副本不漂移。TASK.md 中指向“GPT”的措辞改为“supervisor”，使两个大脑都能驱动同一协议。CLI 路线尚无真机任务验证，首次使用应先派极小任务。

## 2026-10-21 更新

同步已验证的 Windows 执行器修复与不调用 API 的环境检查脚本；新增首次配置后记住本机路径、后续复用和更新保留设置的通用指引。没有导出开发机的个人路径区段，没有更改主 Codex 登录或新发起 API 任务。
