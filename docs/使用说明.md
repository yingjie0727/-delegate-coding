# 大脑控制小脑：小白使用说明

你以后只需要向 GPT 说需求。GPT 负责想方案、分任务、检查结果，具体实现可以交给你选的助手。

这个 skill 的显示名称是“大脑控制小脑”，内部调用名保留为 `$delegate-coding`。你可以直接说“使用大脑控制小脑”。它有两条独立的使用方式：

| 你选的方式 | 谁来做具体工作 | 你需要做什么 |
|---|---|---|
| 桌面助手 | WorkBuddy、ZCode，或以后加入的其他助手 | 把 GPT 给的一段交接文字复制到对应软件；做完后回到 GPT 说“完成” |
| API | DeepSeek 等已配置的模型 | 第一次在本机填写自己的 API 密钥；之后由 GPT 运行执行器 |

**桌面助手这条线不需要申请开放平台应用。** 它通过本机文件交接任务。API 这条线需要单独的接口密钥和费用，不会使用 WorkBuddy 或 ZCode 的登录账号。

## 第一次准备

从仓库的 skills/ 目录找到完整的 delegate-coding 文件夹，安装进自己的 Codex 个人技能目录。可以把仓库链接交给 Codex，请它安装 skills/delegate-coding；也可以手工复制整个文件夹。

Windows 默认个人技能目录是 `%USERPROFILE%\.codex\skills`。设置了 CODEX_HOME 时，使用其下的 skills 目录。已有同名目录时先比较，不要覆盖自己的修改。

安装后在代码项目中使用“大脑控制小脑”，或显式调用 `$delegate-coding`。

## 先用 WorkBuddy：你只用复制一段话

在项目的 GPT 对话里发送下面这段，最后一行换成你的需求：

> 使用 $delegate-coding。你负责方案和验收，走桌面助手这条线，执行器选 WorkBuddy。先检查项目，再给我可以直接复制到 WorkBuddy 的交接文字。我的需求是：给首页增加一个返回顶部按钮。

然后照着做：

1. GPT 看项目、写好任务，并给你交接文字。
2. 打开 WorkBuddy，在正确的项目/工作目录中粘贴发送。如果提示访问任务文件夹或项目文件夹，只开放这次需要的目录。
3. 等 WorkBuddy 做完，回到原来的 GPT 对话说：“WorkBuddy 完成了，请检查实际修改和测试结果。”
4. GPT 检查后告诉你是否通过；有问题就重新写清楚修复要求。

**目前桌面线路仍需要你复制发送，文件生成不会自动让 WorkBuddy 开始。** 任务文件会放在项目目录外的专用交接文件夹，由 GPT 管理；你不需要理解 JSON 或手工运行交接命令。

## 换成 ZCode

用同样的话，把“执行器选 WorkBuddy”改成“执行器选 ZCode”即可。GPT 生成对应交接文字，你粘贴到 ZCode。

ZCode 模板已经预留，但这次尚未在你的电脑上验证。第一次先做一个很小的任务，例如“读取指定文件并写回一段结果”。能完成文件读写和报告后，再交正式代码任务。

如果 ZCode 无法读取目录或运行交接命令，把它的真实报错交给 GPT。不要把“模板已注册”当作“已经接通”。其他桌面助手也可以按相同方式添加，但要逐个验证。

## 改走 API：第一次配置好，以后由 GPT 运行

告诉 GPT：

> 使用 $delegate-coding，走 API 这条线，模型用 DeepSeek 官方接口。请检查执行器是否已配置；缺少密钥时给我本机隐藏输入的方法，不要让我把密钥发到聊天。配置完成后，先做一个最小任务验证。

GPT 会先处理独立配置、执行器和诊断，再创建 API 任务。每个任务会固定使用哪个接口配置，执行时会检查是否还是同一份配置；切换厂商或模型需要明确新建任务。密钥相当于调用接口的通行证；只在本机隐藏输入，**不要发在聊天、截图或任务文件里**。

API 线路会调用模型接口并产生相应费用。它不会把主 GPT 对话改成 DeepSeek，也不会自动改你的 Codex 登录或统一模型菜单。已有的旧版 DeepSeek skill 配置不会在这里被自动认领；GPT 会先核对需要复用的配置。

## 怎么选最省事

- 已经有 WorkBuddy 账号、想先跑通：先选桌面 WorkBuddy。
- 想用 ZCode 的现有功能：选桌面 ZCode，先做文件往返测试。
- 希望以后不用每次复制任务：选 API，配置完后由 GPT 调用。

两条线路会共用任务书和验收办法。失败时 GPT 会告诉你原因，不会悄悄换软件、模型或接口。

## 两个容易踩坑的地方

**同一个项目一次只交给一个助手修改，并一直使用同一个任务板。** 不要同时让 WorkBuddy、ZCode 和 GPT 改同一份文件。任务板就是存放交接文件的地方，由 GPT 管理。skill 的锁只检查同一个任务板，换另一个任务板无法互相保护；它也不能阻止其他软件或你手动修改文件。

**取消桌面任务后，还要在那个软件里停止执行。** 告诉 GPT“取消”只能标记取消请求，不能关闭 WorkBuddy 或 ZCode。确认助手停止后，再让 GPT 检查已有修改并结束任务。

目前已完成封装；WorkBuddy 以前的简单文件交接已验证。新版完整任务协议、ZCode，以及真实 API 调用仍需分别做一次本机验证。GPT 会把“已生成”“已开始”“已报告完成”和“已验收通过”分开说明。
