# 小白使用说明

你把需求告诉 GPT，它负责定方案、分任务和检查结果。具体实现可交给桌面助手，也可调用模型 API。

## 第一步：安装 Skill

把 GitHub 仓库链接交给 Codex，说：

> 请安装仓库里的 skills/delegate-coding 技能，保留已有配置。如果有同名文件，先比较差异。

手工安装时，复制整个 `skills/delegate-coding` 文件夹，不要只复制 `SKILL.md`。Windows 通常放在 `%USERPROFILE%\.codex\skills`；自定义了 `CODEX_HOME` 则使用其下的 `skills`。

安装完后，在代码项目的 Codex 对话里说“使用大脑控制小脑”。Python、Git 或 API 执行器缺少时，让 GPT 检查并说明下一步即可。

## 路径只配置一次

首次使用 API 时可以告诉 GPT：

> 请定位本机 Python、Codex CLI 和随包执行器，检查后把非秘密路径记录到这台电脑的 Skill 安装副本，以后直接读取，不要每次让我提供绝对路径。

随包脚本按实际 Skill 文件夹定位，用户无需单独查找。程序更新或路径改变时让 GPT 重新核对。仅记录路径不会自动解决 Windows 身份差异；需要用户本机启动时，仍由 GPT 准备入口。

本机路径区段不上传 GitHub。更新 Skill 前保留它和自己的其他修改，避免更新后丢失设置。

## 方式一：交给 WorkBuddy

你可以直接说：

> 使用“大脑控制小脑”。你负责规划和验收，交给 WorkBuddy 实现。先检查项目，再给我能直接复制发送的任务文字。需求：……

1. GPT 检查项目，写出边界明确的任务和交接文字。
2. 你在 WorkBuddy 打开任务指定的目录，粘贴并发送交接文字。
3. WorkBuddy 领取任务、修改文件、提交结果。
4. 完成后回到 GPT 说“WorkBuddy 完成了，请验收”。GPT 自己看差异、运行测试，再接受或退回。

不用把 WorkBuddy 写出的整段代码复制回 GPT；两边通过本机共享文件交接。当前仍需要你发送任务、通知完成，Skill 不会自动点击桌面软件。

## 方式二：调用 DeepSeek 官方 API

你可以说：

> 使用“大脑控制小脑”，走 DeepSeek 官方 API 路线。先检查本机配置和 Windows 执行环境；密钥只在本机隐藏输入。先做一个很小的任务，完成后独立验收。

首次使用时，GPT 需要为这台电脑准备独立 API profile、确认模型和 Codex CLI 位置。Windows 要明确选择已配置且获准的沙箱实现，再检查项目内能读写、项目外写入被拒绝。检查本身不读取密钥、不调用模型；失败时先处理环境。

API 密钥只在自己的电脑输入，不要发到聊天、截图、任务书或源码里。Windows 可用当前用户 DPAPI 加密保存，也支持指定的环境变量。隐藏终端输入不显示字符是正常的；若粘贴或输入出错，把错误提示交给 GPT，勿发送密钥内容。

这条路线会使用你自己的 API 额度，与桌面助手的账号或会员各自独立。每项任务固定接口、模型和配置，失败后不会自动换厂商或模型。

开发机已通过“用户启动本机入口 → DeepSeek 实现 → GPT 验收”的小任务。不同电脑的 Windows 身份和凭据权限可能不同；先验证本机启动方式，不能把“装好了 Skill”当作“已能从当前对话全自动调用”。本包没有开发机专用的启动 `.cmd`，由 GPT 按你电脑的实际路径准备入口。

## 换其他执行器

- ZCode：把“交给 WorkBuddy”换成“交给 ZCode”。模板已准备，但需先在自己的电脑做一次文件交接和小任务测试。
- 其他桌面助手：需要能读取任务文件、修改授权项目、运行协议命令并写回报告；GPT 可以登记同类适配器，仍需验证。
- 其他 API：只支持当前 Codex CLI 实际兼容的 Responses 协议，必须另建 profile 并验证流式响应和工具调用。普通聊天接口可用不等于编码执行器可用。

## 日常只记住这些

同一项目一次只交给一个执行器修改，始终使用同一个任务板。助手说“完成”后，回 GPT 让它检查真实代码和测试。不要仅看模型的自述或退出码。

取消桌面任务时，还要在那个软件里让它停止。GPT 标记取消不等于能关闭 WorkBuddy 或 ZCode；确认停止后再结束或创建新任务。

初次上手时先做一个小任务。WorkBuddy 和 DeepSeek 的开发机小任务已通过，ZCode 和其他设备仍要验证自己的环境。
